## 🛠️ **TROUBLESHOOTING**

**Addon not showing?**
- Check folder name is exactly `StatForge` (case-sensitive)
- Try typing `/reload` in-game
- Verify you're using MoP Classic (not retail)

**No recommendations?**
- Your gear might already be optimized!
- Make sure you have reforgeable secondary stats
- Click "Refresh" in the addon window
